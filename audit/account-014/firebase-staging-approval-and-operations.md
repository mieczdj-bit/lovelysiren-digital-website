### Billing and APIs

Cloud Functions for Firebase deployment requires the **Blaze pay-as-you-go plan** and a linked Cloud Billing account. The account deployment may incur Cloud Build, Artifact Registry storage/deployment, Cloud Run/Functions compute, networking/egress, Realtime Database usage and logs. A public website or other shared RTA traffic can affect the same project bill. Firebase currently documents a monthly no-cost tier for Functions invocations/compute/egress on Blaze, but deployment artifacts/storage and other services can still cost money. Budget alerts **do not cap charges**; set a producer-approved budget/alerts and consider a Cloud Run Functions spend cap where supported. The free tier is not a cost guarantee.

Relevant APIs likely involved in a Gen 2 deployment or the existing client/backend flow are Cloud Functions (`cloudfunctions.googleapis.com`), Cloud Build (`cloudbuild.googleapis.com`), Artifact Registry (`artifactregistry.googleapis.com`), Cloud Run (`run.googleapis.com`), Eventarc (`eventarc.googleapis.com`), Firebase/Realtime Database (`firebase.googleapis.com`, `firebasedatabase.googleapis.com`), Identity Toolkit/Auth (`identitytoolkit.googleapis.com`), Secure Token (`securetoken.googleapis.com`), Cloud Storage for deployment source (`storage.googleapis.com`), Service Usage (`serviceusage.googleapis.com`), IAM (`iam.googleapis.com`) and Cloud Logging (`logging.googleapis.com`). Exact enablement can depend on the current Firebase CLI/project state. Inspect before enabling; have Firebase CLI report any required API additions, then obtain approval for that exact list. Do not enable APIs in this pass.

Official current references: [Cloud Functions setup and deployment](https://firebase.google.com/docs/functions), [Firebase billing plans](https://firebase.google.com/docs/projects/billing/firebase-pricing-plans), [Cloud Functions pricing FAQ](https://firebase.google.com/docs/functions/faq-and-troubleshooting), [Firebase spend caps](https://firebase.google.com/docs/projects/billing/spend-caps), [Auth authorized domains](https://firebase.google.com/docs/auth/faq-and-troubleshooting), [Admin SDK database rule-based access](https://firebase.google.com/docs/database/admin/start), [Admin AppOptions databaseAuthVariableOverride](https://firebase.google.com/docs/reference/admin/node/firebase-admin.app.appoptions), [Firebase Auth IAM roles](https://docs.cloud.google.com/iam/docs/roles-permissions/firebaseauth), and [Realtime Database IAM roles](https://docs.cloud.google.com/iam/docs/roles-permissions/firebasedatabase).
